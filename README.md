# 📅 주간 시간표 (WeeklyScheduleApp) - iOS & macOS 네이티브 앱

아이가 스스로 공부·학원·운동·생활 스케줄을 확인하고, 부모님과 실시간으로 진행 상황·확인 도장·❤️ 응원 하트를 주고받는 SwiftUI 네이티브 크로스플랫폼 앱입니다.

## ✨ 주요 기능

1. **아이 폰 ↔ 부모님 폰 실시간 클라우드 동기화 (`VercelBlobSyncService`)**
   - **무료 개인 Apple ID 100% 호환**: 별도의 유료 Apple 개발자 계정 없이도 Vercel Blob 클라우드 스토리지를 통해 아이 폰과 부모님 폰의 **주간 시간표(일정 추가·수정·삭제)**·완료 체크·부모 확인 도장·❤️ 하트 메시지가 실시간 동기화됩니다.
   - **결정론적(Deterministic) 기본 시간표 ID 및 타임스탬프 스마트 병합**: 모든 기기에서 동일한 기준 ID를 사용하여 중복 생성 없이 어느 기기에서든 시간표를 수정하면 다른 기기와 1페이지 출력물에 즉시 반영됩니다.

2. **🖨️ 주간 시간표 A4 가로 1페이지 출력 & PDF·이미지 내보내기 (`SchedulePrintPreviewSheet`)**
   - **참고 PDF 레이아웃 완벽 재현**: 세이지 그린 헤더, 좌측 시간 열, 그리고 토요일 주간 미션(12:00~22:30)·일요일 자유시간(20:00~22:00) 등 장기 일정의 **다중 행 셀 병합(Rowspan)** 디자인을 A4 가로 1페이지 비율로 자동 구성합니다.
   - **AirPrint 1페이지 바로 인쇄 & 벡터 PDF/고화질 이미지 공유**: 아이폰에서 무선 프린터(AirPrint)로 1장에 딱 맞게 바로 인쇄하거나, 선명한 벡터 PDF 및 고해상도 PNG 이미지로 저장·공유(카카오톡, 파일 앱, AirDrop)할 수 있습니다.
   - **3가지 출력 테마 & 완료 도장 표시 옵션**: 클래식 민트(PDF 원본 스타일), 과목별 컬러 스타일, 흑백 잉크 절약 모드 선택이 가능하며, 벽 부착용 깔끔한 시간표 또는 이번 주 완료/부모확인 도장·하트가 찍힌 주간 칭찬 리포트로 선택 출력할 수 있습니다.

3. **10세 아이 맞춤 강화된 부모 확인 보안 (`ParentPinSheet`, `KeychainHelper`)**
   - **기기 역할 분리 (`👦 아이의 폰` vs `👩👨 부모님 폰`)**:
     - **아이의 폰 (아이 모드)**: 스스로 스케줄을 조절하는 습관을 기를 수 있도록 일정 추가·수정·삭제와 `다 했어요` 체크는 열려 있으되, 이미 부모님 확인 도장이 찍힌 숙제는 임의로 해제하거나 삭제할 수 없도록 보호됩니다. 또한 아이 본인의 Face ID로 우회하지 못하도록 아이 폰에서는 생체인증을 차단하고 **오직 부모님 6자리 마스터 PIN**만 허용합니다.
     - **부모님 폰 (부모 모드)**: **Face ID / Touch ID**로 1초 만에 잠금 해제하여 원격으로 숙제 확인 도장을 찍고 하트를 보낼 수 있습니다.
   - **산수 문제 초기화 우회 완전 제거 & 6자리 마스터 PIN (`160125`)**:
     - 10세 아이가 쉽게 풀 수 있었던 기존의 곱셈 문제 PIN 재설정 기능을 완전히 제거했습니다.
     - **6자리 마스터 PIN (기본값: `160125`) + 5회 연속 실패 시 단계별 입력 잠금(60초/300초) + iOS Keychain 암호화 저장**이 적용되어 앱을 재설치하거나 강제 종료해도 잠금을 우회할 수 없습니다.

4. **❤️ 부모님 하트 & 응원 스티커 보내기 (`PraiseHeartSheet`)**
   - 부모님이 각 숙제 항목마다 또는 상단 메인 배너에 **❤️ 하트(+1, +3, +5, +10개)**와 **응원 스티커(❤️, ⭐, 👍, 👏, 🔥, 👑) 및 칭찬 한마디**를 보낼 수 있습니다.
   - 아이 폰의 상단 히어로 배너와 각 일정 카드에 누적 하트 개수와 부모님의 칭찬 메시지가 실시간으로 표시됩니다.

5. **🔄 이번 주 스케줄 조정 vs 📅 전체 스케줄 변경 (`ScheduleEditScope`, `WeeklyItemOverride`)**
   - **오늘의 스케줄 탭 (`TodayScheduleView`) → 기본값: 이번 주만 조정 (`.thisWeek`)**:
     - 학원 보강, 병원 방문, 특별 일정 등으로 **이번 주에만 시간이나 요일을 옮기거나**, **이번 주만 임시 추가(`targetWeekKey`)**, 또는 **이번 주만 휴강·제외(`isSkipped`)**할 수 있습니다.
     - 시간을 옮겨도 이미 체크한 완료 기록·부모님 확인 도장·❤️ 하트가 그대로 보존되며, **다음 주 월요일이 되면 자동으로 원래 기본 시간표로 복구**됩니다.
     - 카드 배지 및 하단 휴강 목록에서 언제든 **`원래대로`** 버튼 한 번으로 개별·요일별·주간 전체 조정을 즉시 되돌릴 수 있습니다.
   - **주간 시간표 탭 (`WeeklyGridView`) → 기본값: 전체 스케줄 변경 (`.master`)**:
     - 매주 반복되는 정규 시간표를 영구적으로 수정·추가·삭제할 수 있으며, 상단 전환 스위치로 **전체 기본 시간표**와 **이번 주 조정 반영 시간표**를 오가며 확인 및 1페이지 인쇄가 가능합니다.

## 💻 macOS 네이티브 앱 (`WeeklyScheduleMac`)
- **맥 데스크톱 맞춤 3단/2단 NavigationSplitView 사이드바**:
  - 📅 **주간 시간표 (와이드 그리드)**: 넓은 맥 화면에서 월~일 전 요일의 시간표를 시원하게 한눈에 확인 및 관리.
  - ✅ **오늘의 스케줄 (일별 체크리스트)**: 오늘 및 특정 요일의 숙제 진행률(완료/전체)과 세부 할 일을 빠르게 확인하고 체크.
  - 🖨️ **1페이지 A4 인쇄 & PDF 내보내기**: `⌘P` 단축키로 macOS 시스템 인쇄 대화상자 호출 및 `NSSavePanel`을 통한 파일 직접 저장.
  - ⚙️ **동기화 및 설정**: 실시간 Vercel Blob 클라우드 상태 확인 및 수동 동기화(`⌘R`), 알람 사운드 테스트.
- **키보드 단축키 & 시스템 메뉴 바**:
  - `⌘N`: 새 일정 추가
  - `⌘R`: 지금 즉시 클라우드 동기화
  - `⌘P`: 주간 시간표 인쇄
  - `⌘L`: 부모 모드 전환 / 잠금
  - PIN 입력 화면에서 키보드 숫자(0~9, 백스페이스) 직접 입력 완벽 지원
- **Mac Touch ID & 마스터 PIN 연동**:
  - 맥북 및 Magic Keyboard의 **Touch ID**를 지원하여 부모 모드 잠금을 1초 만에 해제할 수 있습니다.
- **macOS 전용 정품 앱 아이콘 (Big Sur / Sonoma / Sequoia 디자인 가이드라인 준수)**:
  - 네이티브 스쿼클(Squircle) 라운드 및 소프트 드롭 섀도우가 반영된 macOS 앱 아이콘(`AppIcon.icns`) 내장.

## 🚀 실행 및 배포 방법

### 📦 macOS 앱 배포 패키지 (`dist/`)
- 배포용 DMG 및 ZIP 파일이 프로젝트 루트의 `dist/` 폴더에 생성되어 있습니다:
  - **DMG 설치 파일**: [WeeklyScheduleMac-1.0.1.dmg](file:///Users/jae/Workspace/weekly-schedule/dist/WeeklyScheduleMac-1.0.1.dmg) (더블 클릭 후 Applications 폴더로 드래그하여 설치)
  - **ZIP 압축 파일**: [WeeklyScheduleMac-1.0.1.zip](file:///Users/jae/Workspace/weekly-schedule/dist/WeeklyScheduleMac-1.0.1.zip)
- 현재 사용 중인 Mac의 `/Applications` 폴더에도 즉시 실행할 수 있도록 최신 릴리즈 빌드가 자동 설치되었습니다 (`/Applications/WeeklyScheduleMac.app`).

### 💻 Mac 개발 환경에서 빌드 & 실행 (Xcode)
1. Xcode에서 [WeeklyScheduleApp.xcodeproj](file:///Users/jae/Workspace/weekly-schedule/WeeklyScheduleApp.xcodeproj)를 엽니다.
2. 상단 스킴 선택 메뉴에서 **`WeeklyScheduleMac` > `My Mac`**을 선택합니다.
3. **Run (⌘ + R)**을 누르면 데스크톱 전용 네이티브 macOS 주간 시간표 앱이 즉시 실행됩니다!

### 📱 iOS 설치 (7일마다 Xcode Run)

SideStore는 쓰지 않는다. 이 폰의 무료 서명 슬롯 3개가 이미 EtoGram·툰 뷰어·주간 시간표로 차 있어, SideStore를 넣으면 주간 시간표를 앱으로 되돌릴 수 없다. 7일이 지나면 Xcode에서 다시 Run 한다.

### 📱 Xcode로 직접 설치 (7일마다 맥 필요)
1. 상단 스킴 선택 메뉴에서 **`WeeklyScheduleApp`**을 선택합니다.
2. Xcode 좌측 네비게이터에서 `WeeklyScheduleApp` 프로젝트를 클릭하고 **Signing & Capabilities** 탭으로 이동합니다.
   - **Automatically manage signing** 체크
   - **Team**에서 본인의 Apple ID 계정을 선택합니다.
3. **아이의 아이폰**을 케이블로 연결하고 상단 기기 목록에서 선택한 뒤 **Run (⌘ + R)**을 눌러 설치합니다.
   - 앱 실행 후 상단 배너에서 **`👦 아이의 폰으로 사용`**을 선택합니다.
4. **부모님의 아이폰**을 케이블로 연결하고 **Run (⌘ + R)**을 눌러 설치합니다.
   - 앱 실행 후 상단 배너에서 **`👩👨 부모님 폰으로 설정`**을 누르고 6자리 마스터 PIN(**`160125`**)을 입력하면 이후부터는 **Face ID**로 간편하게 숙제 확인 도장과 ❤️ 하트를 보낼 수 있습니다!
