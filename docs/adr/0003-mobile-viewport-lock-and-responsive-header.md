# 0003. 모바일 웹앱(PWA) 뷰포트 고정 및 반응형 헤더 분리 정책

## Status
Accepted

## Context
스마트폰(iOS Safari 및 모바일 브라우저) 환경에서 모바일 웹앱(PWA) 사용 시 다음 두 가지 문제가 발생했다:
1. **상단 헤더 가로폭 초과**: 로고, 날짜/주차 배지, 응원 하트, 스타, 동기화, 인쇄, 부모 모드 전환 버튼이 단일 가로 행에 밀집되어 모바일 뷰포트(375px~390px)를 초과(520px+), 최우측의 `부모 모드` 버튼이 화면 밖으로 잘리고 가로 스크롤을 유발함.
2. **원치 않는 화면 확대(Zoom)**: 모바일 사파리에서 두 손가락 핀치 줌, 더블 탭 확대, 16px 미만 텍스트 입력창 포커스 시 자동 확대가 발생하여 네이티브 앱과 같은 조작감을 해치고 레이아웃이 깨짐.

## Decision
네이티브 앱과 동일한 사용 경험을 보장하기 위해 상단 헤더 반응형 레이아웃과 화면 확대 방지 정책을 다음과 같이 확정한다:
1. **상단 헤더 2단/3행 분리**:
   - 모바일(`sm` 미만): 1행에 앱 로고(좌)와 핵심 상태/부모 모드 버튼(우)을 배치하여 부모 모드가 온전히 노출되도록 보장하고, 2행에 날짜 및 ISO 주차 배지를 독립 배치하며, 3행에 100% 균등 3분할(`grid grid-cols-3`) 내비게이션 탭 바를 배치한다.
   - 태블릿/PC(`sm` 이상): 단일 가로 행 및 유연한 탭 바 배치를 유지한다.
   - A4 1페이지 인쇄 버튼은 스마트폰 뷰포트에서 숨기고(`hidden sm:flex`), 태블릿/PC 환경에서만 노출한다.
2. **화면 확대(Zoom) 4중 잠금**:
   - **HTML Viewport**: `width=device-width, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0, user-scalable=no, viewport-fit=cover`를 명시한다.
   - **CSS 제스처 제어**: `html, body`에 `touch-action: manipulation`, `overflow-x: hidden`, `-webkit-text-size-adjust: 100%`를 설정하여 더블탭 줌과 가로 밀림을 차단한다.
   - **iOS 사파리 제스처 이벤트 방어**: iOS 10+ WebKit이 메타태그를 무시하고 핀치 줌을 허용하는 문제를 해결하기 위해 `gesturestart`, `gesturechange`, `gestureend` 및 다중 터치(`touches.length > 1`)의 기본 동작(`preventDefault`)을 방어한다.
   - **모바일 폼 입력창 폰트 16px 보장**: iOS 사파리가 16px 미만 입력 필드 포커스 시 화면을 자동 확대하지 않도록 모바일 미디어 쿼리에서 `font-size: 16px !important`를 보장한다.

## Consequences
- 스마트폰(아이폰/갤럭시 등)에서 가로 스크롤 없이 부모 모드 전환, 보상 배지, 탭 메뉴가 한눈에 안정적으로 조작된다.
- 핀치 줌, 더블탭 줌, 인풋 포커스 줌이 완전히 차단되어 네이티브 앱과 구별되지 않는 일관된 터치 조작감을 제공한다.
- 일반적인 웹 브라우저의 자유로운 확대/축소 접근성(WCAG)과는 트레이드오프가 발생하나, 아이와 부모를 위한 전용 일정/습관 관리 PWA 도구로서 안정적인 UI 형태 유지를 우선한다.
