# 02: 실시간 오늘 고정 히어로 카드 및 진행중·다음 일정 바로가기

**What to build:** 하단 요일 선택 바에서 다른 요일의 **일일 스케쥴(Daily Schedule)**을 탐색하더라도 화면 최상단에는 항상 '실제 오늘'을 기준으로 오늘 날짜, 보유 **응원 하트(Praise Heart)** 및 **하트 보상 교환(Heart Reward Redemption)** 진입 버튼, 응원 보내기 버튼, 실제 오늘의 완료·부모 확인 달성률과 응원 메시지, 그리고 현재 시각에 진행 중인 일과(`"지금 하는 일"`)와 `"다음 일정"` 요약을 고정 표시한다. 또한 타임라인 일정 카드의 실시간 `"진행중"` 배지 및 강조 테두리가 오직 실제 오늘 요일의 진행 시간대에만 표시되도록 한다.

**Blocked by:** 01: 월~일 7열 요일 선택 바 및 주간 스타 스탬프 보드 양방향 요일 전환

**Status:** ready-for-agent

- [ ] 최상단 실시간 오늘 현황 히어로 카드는 사용자가 다른 요일을 선택하더라도 항상 실제 오늘(`todayWeekday`) 기준의 날짜, 달성률(`percentage`), 완료 카운트(`다 했어요 X/Y`), 부모 확인 카운트(`부모확인 X/Y`), 슬로건 문구를 유지한다.
- [ ] 히어로 카드 내에 보유 **응원 하트(Praise Heart)** 수와 함께 **하트 보상 교환(Heart Reward Redemption)** 모달을 여는 버튼, 전체 응원 보내기 버튼, 최신 부모님 응원 카드 배너가 통합 표시된다 (기존 테스트 식별자 호환 유지).
- [ ] 실제 오늘의 **일일 스케쥴(Daily Schedule)** 중 현재 시각이 `[시작 시각, 종료 시각)` 범위에 포함되는 `"지금 하는 일"`과 현재 시각 이후 가장 이른 `"다음 일정"`이 히어로 카드 내에 시간대 및 완료 상태와 함께 실시간으로 표시된다.
- [ ] 다른 요일을 조회하던 중 히어로 카드의 `"지금 하는 일"` 또는 `"다음 일정"` 행을 클릭하면 선택 요일(`selectedWeekday`)이 즉시 실제 오늘(`todayWeekday`)로 전환되고 해당 일정으로 포커스/이동한다.
- [ ] 타임라인 일정 카드의 실시간 `"진행중"` 배지 및 활성 강조 테두리는 `selectedWeekday === todayWeekday`이고 현재 시각이 해당 일정의 시간대에 속할 때만 표시되며, 다른 요일을 조회할 때는 같은 시간대라도 `"진행중"` 표시가 나타나지 않는다.
