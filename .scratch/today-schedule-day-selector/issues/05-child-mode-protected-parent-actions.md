# 05: 아이 모드 보호 액션의 부모 PIN 즉시 인증 실행 연동

**What to build:** **아이 모드(Child Mode)**에서도 '오늘 스케쥴' 탭의 보호된 부모 전용 액션 버튼들을 숨기지 않고 화면에 노출하되(잠금 표시 포함), 클릭 시 실행 사유가 적힌 6자리 마스터 PIN 인증 모달을 띄우고 인증에 성공하는 즉시 두 번 클릭할 필요 없이 원래 요청했던 부모 액션을 자동 실행한다.

**Blocked by:** 02: 실시간 오늘 고정 히어로 카드 및 진행중·다음 일정 바로가기, 03: 카테고리 필터 바, 선택 요일 섹션 헤더 및 일괄 확인·완료 초기화, 04: 이번 주 조정 요약·복구 및 타 요일 이동 기본 시간표 복구

**Status:** closed

- [x] **아이 모드(Child Mode)**에서도 다음 부모 보호 액션 버튼들이 숨겨지지 않고 화면에 노출된다:
  - 확인 대기 숙제 일괄 승인 (`"모두 확인 + ❤️"`)
  - 선택 요일 완료 체크 초기화 (`"초기화"`)
  - 이번 주 조정 복구 (`"이번 주 조정 원래대로"` 및 개별 일정 카드의 `"원래대로"`)
  - 휴강 및 타 요일 이동 일정의 `"원래대로 복구"`
  - 히어로 카드의 `"응원 보내기"` 및 개별 일정의 `"응원하기"` / `"수정"`
  - 상단 `"+ 이번 주 추가"` 및 빈 상태 카드의 `"이번 주 일정 추가하기"`
- [x] **부모 모드(Parent Mode)**에서 위 액션들을 클릭하면 PIN 모달 없이 즉시 실행된다.
- [x] **아이 모드(Child Mode)**에서 위 보호 액션 중 하나를 클릭하면 해당 액션의 사유(예: `"일괄 확인 및 하트 지급"`, `"완료 체크 초기화"`, `"이번 주 조정 복구"`, `"제외 일정 복구"`, `"응원 하트 보내기"`, `"이번 주 일정 추가"`)가 표시된 6자리 마스터 PIN 모달이 열린다.
- [x] PIN 모달에서 올바른 6자리 마스터 PIN을 입력하면 **부모 모드(Parent Mode)**로 전환됨과 동시에, 사용자가 다시 버튼을 누르지 않아도 방금 요청했던 액션(상태 변경 또는 해당 편집/응원 모달 오픈)이 즉시 실행된다.
- [x] PIN 모달을 취소하거나 닫으면 대기 중이던 액션은 실행되지 않고 안전하게 폐기된다.
