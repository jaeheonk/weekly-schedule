# 03: 카테고리 필터 바, 선택 요일 섹션 헤더 및 일괄 확인·완료 초기화

**What to build:** 요일 선택 바 아래에 선택 요일의 **일일 스케쥴(Daily Schedule)**을 카테고리별로 필터링할 수 있는 가로 카테고리 필터 바를 제공하고, 선택 요일 섹션 헤더에 요일 전체 이름, `"TODAY"` 배지, `"이번주 조정 N건"` 배지, 선택 요일의 완료·부모 확인 통계, 확인 대기 숙제를 한 번에 도장 찍고 하트를 지급하는 `"모두 확인 + ❤️"` 배너, 그리고 선택 요일의 완료 체크를 초기화하는 `"초기화"` 버튼을 구현한다.

**Blocked by:** 01: 월~일 7열 요일 선택 바 및 주간 스타 스탬프 보드 양방향 요일 전환

**Status:** closed

- [x] 요일 선택 바 하단에 `"전체"` 및 각 일정 카테고리(`공부`, `학원`, `음악`, `운동`, `생활습관`, `자유시간`) 아이콘·색상·해당 요일 일정 개수를 보여주는 카테고리 필터 바가 표시되며, 칩 선택 시 선택 요일의 일정 목록이 즉시 필터링된다.
- [x] 상단 빠른 액션의 `"+ 이번 주 추가"` 버튼 또는 선택 요일에 표시할 일정이 없을 때 나타나는 빈 상태 카드의 `"이번 주 일정 추가하기"` 버튼을 클릭하면, 일정 편집 모달이 현재 선택된 요일(`selectedWeekday`)과 `'이번 주만 적용(thisWeek)'` 범위로 기본 설정되어 열린다.
- [x] 선택 요일 섹션 헤더에 선택 요일의 전체 이름(예: `"수요일"`), 실제 오늘일 때만 표시되는 `"TODAY"` 배지, 해당 요일에 활성화된 **이번 주 조정(Weekly Override)** 건수가 1건 이상일 때 표시되는 `"이번주 조정 N건"` 배지가 렌더링된다.
- [x] 선택 요일 섹션 헤더에 실제 오늘 통계와 분리된 해당 선택 요일의 `아이 완료/전체` 및 `부모확인 확인/전체` 통계가 표시된다.
- [x] 선택 요일에 아이가 완료 체크했으나 아직 부모 확인 도장을 받지 않은 대기 항목(`completed > verified`)이 1개 이상 있으면 주황색 안내 배너(`"아이가 '다 했어요' 체크한 숙제 N개가 부모님 확인을 기다리고 있어요!"`)와 `"모두 확인 + ❤️"` 버튼이 나타난다.
- [x] `"모두 확인 + ❤️"` 실행 시 선택 요일의 모든 확인 대기 항목(세부 할 일 포함)에 부모 확인 도장이 일괄 날인되고, 새로 확인된 각 항목마다 **응원 하트(Praise Heart)** `+1`개가 지급된다.
- [x] 선택 요일에 완료된 항목이 1개 이상 있을 때 선택 요일 헤더에 `"초기화"` 버튼이 표시되며, 실행 시 해당 요일의 이번 주 아이 완료 체크 및 부모 확인 도장 기록이 초기화된다.
