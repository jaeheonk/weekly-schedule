# 01: 월~일 7열 요일 선택 바 및 주간 스타 스탬프 보드 양방향 요일 전환

**What to build:** 웹앱의 '오늘 스케쥴' 탭에서 시스템 시계의 실제 오늘 요일뿐 아니라 이번 주 월요일부터 일요일(`1..7`) 중 원하는 요일을 선택하여 해당 요일의 **일일 스케쥴(Daily Schedule)**을 조회하고, 완료 체크·세부 할 일 체크·부모 확인 도장·응원 하트 전송·평일 스타 적립을 수행할 수 있게 한다. 375px 모바일 화면에서도 가로 스크롤 없이 한 줄에 표시되는 월~일 7열 요일 선택 바를 제공하고, 주간 스타 스탬프 보드의 평일 슬롯과 선택 요일을 양방향으로 연동한다.

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] 앱 초기 로드 및 새로고침 시 선택 요일(`selectedWeekday`)이 실제 오늘 요일(`todayWeekday`)로 초기화되며, 같은 세션 내에서 상단 탭(`오늘 스케쥴` ↔ `주간 시간표` / `스타 상점`)을 오가도 선택했던 요일이 유지된다.
- [x] 앱을 켜둔 채 자정이 지나 실제 날짜(요일)가 바뀌면 주기적 시간 점검 및 창 포커스 점검을 통해 `selectedWeekday`가 새로운 실제 오늘 요일로 자동 전환된다.
- [x] 375px 모바일 뷰포트에서도 가로 스크롤이나 잘림 없이 한 줄에 들어가는 월~일 7열 균등 폭 요일 선택 바가 렌더링된다 (ADR-0003 준수).
- [x] 각 요일 선택 버튼은 3단 구조로 표시된다:
  - 상단 마이크로 라벨: 실제 오늘이면 `"오늘"`, 스타 수여 가능 상태이면 `"수여"`, 해당 요일에 활성화된 **이번 주 조정(Weekly Override)**이 있으면 `"조정"`, 해당 사항이 없으면 레이아웃 높이를 유지하는 빈 자리 표시자.
  - 중단 요일명: `월`~`일` 단축 요일명 (비선택 상태에서 토요일은 파란색, 일요일은 빨간색, 선택 상태에서는 강조 배경 위 흰색 텍스트).
  - 하단 상태 인디케이터: 스타 수여 완료 시 별 아이콘, 스타 수여 가능 시 반짝이 아이콘, 체크 가능한 모든 일정이 부모 확인 완료된 경우 인장 아이콘, 아이 완료 체크가 모두 끝난 경우 완료 체크 아이콘, 일부 완료 또는 조정이 있는 경우 상태 점(dot).
- [x] 실제 오늘이 아닌 다른 요일을 보고 있을 때 상단 액션 영역에 `"오늘"` 버튼이 나타나며, 클릭 즉시 `selectedWeekday`가 실제 오늘 요일로 복귀한다.
- [x] 주간 스타 스탬프 보드 카드에서 평일(월~금) 슬롯을 탭하면 `selectedWeekday`가 해당 요일로 전환되고 선택 강조 링이 표시되며, 스타 수여 가능 배너(`+1⭐`)는 현재 선택된 요일이 수여 가능할 때 해당 요일을 최우선 타겟으로 표시한다.
- [x] 토요일(`6`) 또는 일요일(`7`)을 선택한 상태에서 주간 스타 스탬프 보드를 펼치면 `"주말(토·일)은 자유 일정으로 평일 스타 적립 대상에서 제외돼요."` 안내 문구가 표시된다.
- [x] 실제 오늘이 아닌 요일(평일 및 주말 포함)을 선택한 상태에서도 이번 주 **일일 스케쥴(Daily Schedule)** 항목 및 세부 할 일의 `'다 했어요'` 완료 체크, 부모 확인 도장 날인·취소, 개별 일정 **응원 하트(Praise Heart)** 전송이 실제 오늘과 동일하게 동작한다.
