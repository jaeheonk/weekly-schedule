# 01: 핵심 하트 보상 교환 트레이서 불릿 (Core Heart Reward Exchange)

**What to build:** 사용자가 상단 헤더의 하트 배지를 탭하여 보상 교환 모달을 열고, 잔액 히어로 카드(보유/획득/사용 하트)와 8종 기본 추천 보상 그리드를 확인한 뒤, 프리셋 선택 또는 직접 입력을 통해 하트를 교환(차감)할 수 있는 엔드투엔드 흐름. 교환 시 보유 하트 잔액이 즉시 차감되고 축하 사운드와 토스트가 표시되며 로컬 저장소 및 동기화 스냅샷에 기록됩니다.

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] 상단 네비게이션 헤더의 하트 잔액 배지를 탭하면 하트 보상 교환 모달이 열린다.
- [x] 모달 상단 히어로 카드에 사용 가능한 하트, 누적 획득 하트, 총 사용 하트 및 현재 사용자 모드 배지가 표시된다.
- [x] iOS 기본값과 동일한 8종 기본 추천 보상 그리드(게임, 간식, 선물, 나들이, 용돈, 영화, 늦게 자기, 저녁 메뉴)가 표시된다.
- [x] 추천 보상 카드를 탭하면 보상 제목과 필요 하트 수가 입력 폼에 자동으로 채워진다.
- [x] 원하는 보상명이 없는 경우 직접 텍스트로 보상 제목을 입력할 수 있다.
- [x] 스텝퍼(-/+) 버튼 및 퀵 칩(+5, +10, +15, +20)을 눌러 교환할 하트 수를 조절할 수 있다.
- [x] 하트 교환 실행 시 보유 잔액에서 차감되고, 50건 링버퍼 교환 기록이 생성되며, 축하 사운드(Web Audio) 및 완료 토스트가 표시된다.
- [x] 도메인 저장소 및 모달 컴포넌트의 단위/통합 테스트가 작성되어 정상 통과한다.
