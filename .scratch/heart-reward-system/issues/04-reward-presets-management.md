# 04: 추천 보상 프리셋 커스텀 관리 모달 (Preset Management & Emoji Palette)

**What to build:** 추천 보상 프리셋 관리 모달과 이모지 선택 기반 추가/수정 모달을 제공하여, 가족의 고유한 보상 기준에 맞게 프리셋을 자유롭게 등록·수정·삭제하고 필요 시 기본값으로 초기화할 수 있는 전체 관리 기능 (아이 모드 시 PIN 보호 포함).

**Blocked by:** 01: 핵심 하트 보상 교환 트레이서 불릿 (Core Heart Reward Exchange), 02: 아이 모드 6자리 마스터 PIN 승인 및 상세 수량 조절기 (PIN Auth & Advanced Controls)

**Status:** closed

- [x] 보상 교환 모달 상단/프리셋 헤더에 "추천 보상 관리" 버튼이 제공된다.
- [x] 아이 모드에서 "추천 보상 관리" 클릭 시 6자리 마스터 PIN 인증을 요구하며, 부모 모드에서는 즉시 열린다.
- [x] 프리셋 관리 모달에서 현재 등록된 모든 프리셋 목록(이모지, 제목, 카테고리 태그, 하트 비용)이 표시된다.
- [x] 불필요한 프리셋을 삭제할 수 있으며, 클라우드 동기화 툼스톤(삭제 타임스탬프)이 정상 기록된다.
- [x] 기존 프리셋의 이모지, 제목, 필요 하트 수, 카테고리 태그를 수정할 수 있다.
- [x] 16종 이모지 팔레트 그리드가 포함된 추가/수정 서브 모달을 통해 새 추천 보상을 등록할 수 있다.
- [x] "기본값 복원" 버튼을 누르면 확인 다이얼로그를 거쳐 초기 8종 추천 보상으로 초기화된다.
- [x] 프리셋 추가/수정/삭제/초기화 결과가 교환 모달의 프리셋 그리드에 즉시 반영되고 스토리지에 동기화된다.
- [x] 프리셋 CRUD, 툼스톤 추적 및 관리 모달 인터랙션에 대한 단위/통합 테스트가 작성되어 정상 통과한다.
