# 03: 최근 교환 내역 조회 및 부모 전용 환급/취소 (Redemption History & Refunds)

**What to build:** 하트 보상 교환 모달 내에서 최근 교환 내역(최대 50건)을 시간순으로 조회하고, 부모 모드에서 실수나 약속 변경으로 발생한 교환 내역을 취소하여 사용한 하트를 즉시 환급/복구하는 엔드투엔드 흐름.

**Blocked by:** 01: 핵심 하트 보상 교환 트레이서 불릿 (Core Heart Reward Exchange)

**Status:** closed

- [x] 모달 하단 섹션에 최근 보상 교환 내역(최신순 최대 50건)이 표시된다.
- [x] 각 내역 항목에 보상 제목, 차감된 하트 수, 교환 일시, 교환 요청 역할 배지가 올바르게 렌더링된다.
- [x] 교환 내역이 없을 경우 친절한 빈 상태(Empty State) 안내가 표시된다.
- [x] 부모 모드에서는 각 내역 항목 우측에 "취소/환급" 버튼이 노출된다 (아이 모드에서는 미노출).
- [x] "취소/환급" 클릭 시 확인 팝업/모달이 표시되어 오조작을 방지한다.
- [x] 환급 확정 시 해당 교환 내역이 목록에서 제거되고, 차감되었던 하트가 사용 가능한 잔액으로 즉시 복구된다.
- [x] 환급 완료 알림 토스트("↩️ [...] 교환이 취소되어 하트 N개가 복구되었어요.")가 표시된다.
- [x] 내역 렌더링, 환급 처리 및 잔액 복구에 대한 단위/통합 테스트가 작성되어 정상 통과한다.
