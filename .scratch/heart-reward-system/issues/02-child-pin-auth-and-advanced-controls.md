# 02: 아이 모드 6자리 마스터 PIN 승인 및 상세 수량 조절기 (PIN Auth & Advanced Controls)

**What to build:** 아이 모드에서 보상 교환을 요청할 때 부모의 6자리 마스터 PIN 인증을 요구하여 승인 절차를 거치도록 보호하고, 수량 조절 편의성을 위해 연속 슬라이더와 전액(All-in) 칩, 초과 지출 방지 안전장치를 완성합니다.

**Blocked by:** 01: 핵심 하트 보상 교환 트레이서 불릿 (Core Heart Reward Exchange)

**Status:** ready-for-agent

- [ ] 아이 모드에서 교환 버튼을 누르면 "보상 교환 승인" 사유와 함께 6자리 마스터 PIN 모달이 나타난다.
- [ ] 올바른 PIN을 입력하면 자동으로 교환이 승인되고 모달이 닫히며 하트 차감 및 사운드/토스트가 실행된다.
- [ ] 잘못된 PIN 입력 시 오류 메시지가 표시되며 재시도를 유도한다.
- [ ] 부모 모드에서는 PIN 입력 없이 즉시 교환된다.
- [ ] 1개부터 보유 하트 잔액까지 직관적으로 조절할 수 있는 연속 슬라이더(range slider)가 동작한다.
- [ ] "전액(All-in)" 퀵 칩을 누르면 현재 보유한 잔여 하트 전액으로 즉시 수량이 설정된다.
- [ ] 교환 후 남을 예상 하트 수가 실시간으로 미리보기로 표시된다.
- [ ] 보유 하트보다 많은 수량을 입력하거나 0 이하일 경우 교환 버튼이 비활성화되고 초과 경고 메시지가 표시된다.
- [ ] PIN 연동 및 조절기 동작에 대한 단위/통합 테스트가 작성되어 정상 통과한다.
