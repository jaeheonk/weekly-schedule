# 04: 6자리 부모 PIN 보안 인증, 잠금 제한 및 부모 확인 도장·응원 하트

**What to build:**
보호자가 6자리 마스터 PIN을 입력하여 부모 모드(Parent Mode)로 안전하게 전환할 수 있도록 하고, 5회 연속 오류 시 60초 잠금 제한을 적용합니다. 부모 모드에서는 아이가 완료한 일정에 확인 도장을 날인하거나 회수할 수 있고, 다양한 크기의 응원 하트(+1, +3, +5, +10)와 스티커, 격려 코멘트를 전송하여 아이 화면에 실시간으로 표시되도록 합니다.

**Blocked by:** 03: Vercel Blob 클라우드 동기화 및 타임스탬프 결정론적 스냅샷 병합

**Status:** resolved

- [x] 상단 모드 전환 버튼을 통해 6자리 PIN 입력 다이얼로그가 열리고, 올바른 PIN 입력 시 부모 모드로 전환된다.
- [x] PIN 입력을 5회 연속 실패할 경우 60초 동안 PIN 입력이 잠금(Lockout)되며 남은 대기 시간이 실시간 카운트다운된다.
- [x] 부모 모드에서는 완료된 일정 및 서브태스크에 부모 확인 도장('참 잘했어요')을 찍거나 도장을 취소할 수 있다.
- [x] 부모 모드에서 응원 하트 시트를 통해 하트 개수(+1, +3, +5, +10), 스티커 이모지, 칭찬 한마디를 입력하여 전송할 수 있다.
- [x] 전송된 하트와 칭찬 코멘트는 해당 일정 카드와 배너에 즉시 반영되며, 클라우드 스냅샷을 통해 모든 기기에 동기화된다.
- [x] PIN 인증/잠금 타이머 로직 및 부모 확인 도장, 하트 전송 상태 변경을 검증하는 단위 테스트가 통과한다.
