# 03: Vercel Blob 클라우드 동기화 및 타임스탬프 결정론적 스냅샷 병합

**What to build:**
별도의 중계 서버 없이 브라우저에서 직접 Vercel Blob 스토리지와 CORS 통신하여 기존 iOS/macOS 네이티브 앱과 양방향 실시간 동기화를 구현합니다. 결정론적 타임스탬프 병합 알고리즘을 통해 충돌 없이 스케줄 데이터, 완료 체크, 오버라이드, 부모 확인 도장 상태를 최신 상태로 유지하며, 백그라운드 폴링과 수동 동기화, 시각적 토스트 알림을 제공합니다.

**Blocked by:** 02: 아이 모드 일일 체크리스트, 진행률 게이지 및 Web Audio 효과음

**Status:** ready-for-agent

- [ ] Vercel Blob REST API를 통해 가족 채널의 최신 클라우드 동기화 스냅샷(CloudSyncSnapshot v5)을 조회 및 다운로드하고, 변경사항을 새 스냅샷으로 안전하게 업로드할 수 있다.
- [ ] 로컬 상태와 원격 스냅샷 간의 충돌 시 삭제 타임스탬프와 최종 수정 타임스탬프를 기준으로 결정론적인 최신 상태 병합이 수행된다.
- [ ] 브라우저 탭 활성화(visibilitychange) 복귀 시 및 30초 주기 백그라운드 폴링을 통해 최신 스냅샷을 자동으로 가져온다.
- [ ] 상단 동기화 버튼 클릭 또는 ⌘R / Ctrl+R 단축키 입력 시 강제 즉시 동기화가 실행된다.
- [ ] 동기화 완료 또는 오류 발생 시 화면 상단에 플로팅 그라디언트 토스트 배너로 상태가 사용자에게 명확히 피드백된다.
- [ ] 스냅샷 직렬화/역직렬화 및 타임스탬프 병합 규칙을 검증하는 단위 테스트가 통과한다.
