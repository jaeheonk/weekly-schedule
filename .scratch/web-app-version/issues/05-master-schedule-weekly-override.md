# 05: 기본 시간표 편집 관리 및 이번 주 조정(Weekly Override) 기능

**What to build:**
부모 모드에서 매주 반복되는 정규 기본 시간표(Master Schedule) 항목을 추가, 수정, 삭제할 수 있는 편집 기능을 제공하고, 이번 주차에만 한시적으로 일정을 시간 이동하거나 요일을 바꾸거나 휴강 처리할 수 있는 이번 주 조정(Weekly Override) 기능을 구현합니다. 이번 주 조정 내역은 주차가 지나면 자동으로 기본 시간표로 복구됩니다.

**Blocked by:** 04: 6자리 부모 PIN 보안 인증, 잠금 제한 및 부모 확인 도장·응원 하트

**Status:** ready-for-agent

- [ ] 부모 모드에서 기본 시간표의 일정을 새로 추가하거나 기존 일정의 제목, 카테고리, 요일, 시작/종료 시간, 세부 서브태스크를 수정 및 삭제할 수 있다.
- [ ] 특정 일정을 이번 주에만 일시적으로 다른 시간이나 요일로 변경하거나 휴강(취소)할 수 있는 이번 주 조정(Weekly Override) 기능이 동작한다.
- [ ] 이번 주 조정이 적용된 일정은 시간표 및 일일 목록에 조정 배지와 함께 표시된다.
- [ ] 현재 주차(ISO-8601 WeekKey)가 변경되면 이번 주 조정 내역이 영향을 주지 않고 기본 시간표 일정으로 자동 복귀하여 표시된다.
- [ ] 기본 시간표 CRUD 및 주차별 오버라이드 계산(삭제, 시간 변경, 요일 이동) 로직을 검증하는 단위 테스트가 통과한다.
