# 05: 기본 시간표 편집 관리 및 이번 주 조정(Weekly Override) 기능

**What to build:**
부모 모드에서 매주 반복되는 정규 기본 시간표(Master Schedule) 항목을 추가, 수정, 삭제할 수 있는 편집 기능을 제공하고, 이번 주차에만 한시적으로 일정을 시간 이동하거나 요일을 바꾸거나 휴강 처리할 수 있는 이번 주 조정(Weekly Override) 기능을 구현합니다. 이번 주 조정 내역은 주차가 지나면 자동으로 기본 시간표로 복구됩니다.

**Blocked by:** 04: 6자리 부모 PIN 보안 인증, 잠금 제한 및 부모 확인 도장·응원 하트

**Status:** resolved

- [x] 부모 모드에서 기본 시간표의 일정을 새로 추가하거나 기존 일정의 제목, 카테고리, 요일, 시작/종료 시간, 세부 서브태스크를 수정 및 삭제할 수 있다.
- [x] 특정 일정을 이번 주에만 일시적으로 다른 시간이나 요일로 변경하거나 휴강(취소)할 수 있는 이번 주 조정(Weekly Override) 기능이 동작한다.
- [x] 이번 주 조정이 적용된 일정은 시간표 및 일일 목록에 조정 배지와 함께 표시된다.
- [x] 현재 주차(ISO-8601 WeekKey)가 변경되면 이번 주 조정 내역이 영향을 주지 않고 기본 시간표 일정으로 자동 복귀하여 표시된다.
- [x] 기본 시간표 CRUD 및 주차별 오버라이드 계산(삭제, 시간 변경, 요일 이동) 로직을 검증하는 단위 테스트가 통과한다.

## Comments

- **기본 시간표 CRUD 및 부모 모드 보안 보호**: `ScheduleStore`에 `addItem`, `updateItem`, `deleteItem`을 구현하고 기본 시간표 편집/삭제 시 부모 모드 인증을 강제.
- **이번 주 조정(Weekly Override) 엔진**: 주차별 ISO-8601 `WeekKey`와 `baseItemId` 기반 오버라이드 맵 계산, 원본 복구 시 오버라이드 자동 비활성화, 시간/요일 이동 및 이번 주 추가 일정 지원.
- **주차 전환 자동 원복**: `targetWeekKey` 및 `weeklyOverrides`가 현재 주차와 다를 경우 기본 시간표로 자동 복원 계산 검증 완료.
- **휴강(취소) 및 조정 배지**: 일정별 상세 조정 내역(시간 조정, 요일 이동, 휴강·제외 등) 배지 문구 생성 및 주간 와이드 그리드 / 일일 체크리스트 휴강 섹션 표시 및 원클릭 복구 연동.
- **일정 편집 모달 (`ScheduleEditModal`)**: 적용 범위(기본 시간표 vs 이번 주 조정), 과목 분류, 반복 요일 다중 선택, 시간 자동 보정, 세부 서브태스크 관리, 휴강/복구/삭제 액션 완비.
- **전체 테스트 100% 통과**: 신규 단위/통합 테스트 18개 추가(총 93개 테스트) 및 프로덕션 빌드 무결성 검증 완료.
