# 07: A4 1페이지 가로 규격 다중 테마 인쇄 엔진

**What to build:**
냉장고나 벽에 부착할 수 있도록 주간 시간표를 A4 가로(Landscape) 규격 정확히 1페이지로 인쇄하는 전용 인쇄 엔진을 구축합니다. 3가지 스타일 테마(Classic Mint, Subject Color, B&W Ink Saver)를 선택할 수 있고, 확인 도장 및 응원 하트의 인쇄 포함 여부를 선택할 수 있는 미리보기 모달을 제공합니다.

**Blocked by:** 04: 6자리 부모 PIN 보안 인증, 잠금 제한 및 부모 확인 도장·응원 하트

**Status:** ready-for-agent

- [ ] 상단 인쇄 버튼을 통해 인쇄 미리보기 모달(#print)이 열리고, 인쇄될 시간표 레이아웃을 사전에 확인할 수 있다.
- [ ] 세이지 그린 헤더의 Classic Mint, 파스텔 과목 색상의 Subject Color, 잉크 절약용 B&W Ink Saver 3가지 테마 중 하나를 선택할 수 있다.
- [ ] 완료 확인 도장과 응원 하트를 인쇄물에 표시할지, 깨끗한 빈 서식으로 출력할지 토글할 수 있다.
- [ ] 브라우저 인쇄 실행 시 `@media print` 스타일 및 `@page { size: landscape; margin: 8mm; }`가 적용되어 A4 용지 정확히 1장에 여백 잘림이나 페이지 넘어감 없이 들어맞는다.
- [ ] 인쇄 옵션 변경에 따른 뷰 모델 상태 및 인쇄용 스타일 클래스 적용을 검증하는 단위 테스트가 통과한다.
