# 07: A4 1페이지 가로 규격 다중 테마 인쇄 엔진

**What to build:**
냉장고나 벽에 부착할 수 있도록 주간 시간표를 A4 가로(Landscape) 규격 정확히 1페이지로 인쇄하는 전용 인쇄 엔진을 구축합니다. 3가지 스타일 테마(Classic Mint, Subject Color, B&W Ink Saver)를 선택할 수 있고, 확인 도장 및 응원 하트의 인쇄 포함 여부를 선택할 수 있는 미리보기 모달을 제공합니다.

**Blocked by:** 04: 6자리 부모 PIN 보안 인증, 잠금 제한 및 부모 확인 도장·응원 하트

**Status:** resolved

- [x] 상단 인쇄 버튼을 통해 인쇄 미리보기 모달(#print)이 열리고, 인쇄될 시간표 레이아웃을 사전에 확인할 수 있다.
- [x] 세이지 그린 헤더의 Classic Mint, 파스텔 과목 색상의 Subject Color, 잉크 절약용 B&W Ink Saver 3가지 테마 중 하나를 선택할 수 있다.
- [x] 완료 확인 도장과 응원 하트를 인쇄물에 표시할지, 깨끗한 빈 서식으로 출력할지 토글할 수 있다.
- [x] 브라우저 인쇄 실행 시 `@media print` 스타일 및 `@page { size: landscape; margin: 8mm; }`가 적용되어 A4 용지 정확히 1장에 여백 잘림이나 페이지 넘어감 없이 들어맞는다.
- [x] 인쇄 옵션 변경에 따른 뷰 모델 상태 및 인쇄용 스타일 클래스 적용을 검증하는 단위 테스트가 통과한다.

## Answer

A4 1페이지 가로 규격 다중 테마 인쇄 엔진을 구현 완료했습니다:
1. **인쇄 도메인 및 레이아웃 엔진 (`printLayout.ts`)**:
   - `getPrintableTimeSlots`: 기본 14개 시간 슬롯과 사용자 추가 일정의 시작 시간을 자동 결합하여 정렬된 슬롯 목록 생성.
   - `buildPrintColumnBlocks`: 토요일 주간 미션 및 자유시간 등 다중 시간대 연속 일정을 하나의 블록으로 병합(`mergeLongBlocks`)하여 깔끔한 표 레이아웃 산출.
   - 3대 테마 팔레트:
     - `Classic Mint`: PDF 원본 스타일 (세이지 그린 헤더 `#DAE9E2`, 시간열 연민트 `#ECF1EF`, 장기 블록 연민트 `#E9F4EF`).
     - `Subject Color`: 카테고리별 파스텔 컬러 배경 및 네이비 헤더 (`#233878`).
     - `B&W Ink Saver`: 잉크 절약용 고대비 흑백 모드.
   - 텍스트 포맷터: 긴 제목 자연스러운 줄바꿈, 시간 토큰 추출 및 슬롯 중간 종료 표시(`(~16:30)`).
2. **실시간 A4 가로 미리보기 모달 (`SchedulePrintModal.tsx` - #print)**:
   - 상단 내비게이션 바 및 주간 그리드 뷰에 '인쇄' 버튼을 배치하고 URL 해시 `#print`와 동기화.
   - 842x595(1.414:1) 표준 A4 가로 비율의 실시간 반응형 미리보기 카드.
   - 3개 테마 원클릭 전환, 완료 도장/응원 하트 출력 토글, 기본 시간표 vs 이번 주 조정 선택 지원.
   - 단축키 `⌘P`(바로 인쇄) 및 `ESC`(닫기) 지원.
3. **엄격한 A4 1페이지 CSS 인쇄 규격 (`index.css`)**:
   - `@page { size: landscape; margin: 8mm; }` 적용.
   - `@media print`에서 `header, nav, main, aside, footer, button` 등 인터랙티브 UI를 완전 숨김 처리하고 `.printable-sheet`가 194mm 높이에 정확히 수렴하여 용지 1장에 여백 잘림 및 페이지 넘어감 없이 출력되도록 보장.
4. **검증**:
   - 단위/통합 테스트 (도메인, 모달 컴포넌트, 내비게이션 연동) 17개 테스트 파일 123개 테스트 100% 통과 및 프로덕션 빌드 타입체크 완료.
