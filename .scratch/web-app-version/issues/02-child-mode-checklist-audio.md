# 02: 아이 모드 일일 체크리스트, 진행률 게이지 및 Web Audio 효과음

**What to build:**
아이 모드(Child Mode)에서 아이가 오늘 해야 할 일정과 세부 항목(서브태스크)을 확인하고, '다 했어요' 체크박스를 클릭해 완료 상태를 토글하며, 경쾌한 칭찬 차임벨 소리와 함께 일일 달성률 프로그레스 바가 즉시 차오르는 즉각적인 성취 피드백을 제공합니다. 부모 확인 도장이 찍힌 항목은 아이가 임의로 체크를 해제할 수 없도록 보호됩니다.

**Blocked by:** 01: 웹앱 스캐폴딩, PWA 환경 구성 및 GitHub Pages 자동 배포 파이프라인

**Status:** ready-for-agent

- [ ] 아이 모드에서 오늘의 일정 카드 및 하위 서브태스크 체크박스를 클릭하여 완료 상태를 토글할 수 있다.
- [ ] 항목 또는 서브태스크 완료 체크 시 Web Audio API로 합성된 밝고 경쾌한 칭찬 차임벨 사운드가 지연 없이 재생된다.
- [ ] 완료된 항목 수와 전체 항목 비율에 따라 상단 진행률 프로그레스 바와 달성 퍼센트(%)가 실시간으로 애니메이션과 함께 갱신된다.
- [ ] 부모 확인 도장이 완료된 항목이나 서브태스크는 아이 모드에서 클릭하더라도 완료 체크가 해제되지 않도록 보호된다.
- [ ] 일일 완료 상태 및 서브태스크 체크 상태가 브라우저 로컬 저장소에 주차(WeekKey) 및 일정 ID 기준으로 영속화되어 새로고침 후에도 유지된다.
- [ ] 체크리스트 완료 토글, 진행률 계산, 부모 확인 항목 보호 로직을 검증하는 단위 테스트가 통과한다.
